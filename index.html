File Explorer

Unity / Metadata

Chưa có kết quả. Tải IPA ở mục “Phân tích IPA” rồi bấm Bắt đầu phân tích. Các bước này dò thành phần Unity, chọn file global-metadata.dat và kiểm tra header/phiên bản trích xuất string literal và assembly/class/method/field (khi version có bố cục xác minh).
